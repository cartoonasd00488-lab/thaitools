## 📂 หมวด 1: งานเอกสารและเขียนเนื้อหา

### 1.1 เขียนบทความ SEO
```
เขียนบทความภาษาไทยเกี่ยวกับ "[หัวข้อ]" ความยาว 1000-1500 คำ 
รูปแบบ: มีหัวข้อ H2, ย่อหน้า, bullet points 
SEO Keywords: [คีย์เวิร์ด1], [คีย์เวิร์ด2], [คีย์เวิร์ด3]
เขียนแบบเป็นธรรมชาติ ไม่เหมือน AI เขียน
```

### 1.2 สรุปเอกสาร
```
สรุปเอกสารต่อไปนี้ให้กระชับ เป็นภาษาไทย 
แบ่งเป็น 3 ส่วน: ใจความสำคัญ, รายละเอียด, ข้อควรจำ
ความยาว 20% ของข้อความต้นฉบับ

[วางข้อความที่นี่]
```

### 1.3 เขียนอีเมลธุรกิจ
```
เขียนอีเมลภาษาไทยสำหรับ [สถานการณ์]
โทนเสียง: [ทางการ / กึ่งทางการ / เป็นกันเอง]
เนื้อหา: [สั้นๆ ว่าต้องการสื่ออะไร]
ขอให้มี: หัวเรื่อง, คำขึ้นต้น, เนื้อหา, คำลงท้าย, ลายเซ็น
```

### 1.4 รีไรท์เนื้อหา
```
ช่วยเรียบเรียงข้อความต่อไปนี้ใหม่ ให้อ่านง่ายขึ้น 
ใช้ภาษาที่เป็นธรรมชาติ เหมาะกับคนไทย 
รักษาใจความสำคัญไว้ทั้งหมด

[วางข้อความที่นี่]
```

### 1.5 เขียนคำอธิบายสินค้า
```
เขียนคำอธิบายสินค้าสำหรับ Shopee/LAZADA
สินค้า: [ชื่อสินค้า]
จุดเด่น: [จุดเด่น 3-5 ข้อ]
กลุ่มเป้าหมาย: [กลุ่มลูกค้า]
ความยาว: 100-200 คำ ภาษาไทย
รวม: ชื่อสินค้า, จุดเด่น, รายละเอียด, การรับประกัน, hashtag
```

## 📂 หมวด 2: การตลาดและโซเชียลมีเดีย

### 2.1 เขียนโพสต์ Facebook
```
เขียนโพสต์ Facebook ภาษาไทย สำหรับเพจเกี่ยวกับ [หัวข้อ]
วัตถุประสงค์: [สร้าง engagement / ขายของ / ให้ความรู้]
ความยาว: 100-200 คำ
รวม CTA (Call to Action) ด้วย
ใช้ภาษา [ทางการ / สนุกสนาน / ให้ความรู้]
```

### 2.2 เขียน Script TikTok
```
เขียนสคริปต์ TikTok ภาษาไทย ความยาว 30-60 วินาที
หัวข้อ: [หัวข้อ]
Hook (3 วิแรก): ดึงดูดความสนใจ
เนื้อหา: ข้อมูลที่น่าสนใจ
CTA: ชวนกดติดตาม/แชร์
```

### 2.3 วางแผนคอนเทนต์
```
ช่วยวางแผนคอนเทนต์ 1 เดือนสำหรับเพจเกี่ยวกับ [หัวข้อ]
จำนวน: 8-12 โพสต์/เดือน
แต่ละโพสต์มี: หัวข้อ, รูปแบบ(รูป/วิดีโอ/ข้อความ), คำบรรยายสั้น
วิเคราะห์: engagement ที่คาดหวัง
```

### 2.4 เขียน Email Marketing
```
เขียน Email Marketing สำหรับ [โปรโมชั่น/สินค้าใหม่]
กลุ่มเป้าหมาย: [ลูกค้าเก่า/ลูกค้าใหม่]
วัตถุประสงค์: [เปิดร้าน/ขายของ/สร้างแบรนด์]
โทน: [อบอุ่น/เร่งด่วน/ให้ข้อมูล]
รวม: Subject Line, Preview Text, Body, CTA
```

### 2.5 ทำ Keyword Research
```
ช่วยหา Keywords สำหรับ SEO ในหัวข้อ [หัวข้อ]
แบ่งเป็น:
- คำหลัก (High Volume, High Competition)
- คำรอง (Medium Volume, Medium Competition)
- คำยาว (Long-tail, Low Competition)
- คำแนะนำเนื้อหา
ภาษาไทยเท่านั้น
```

## 📂 หมวด 3: ไอเดียและวางแผน

### 3.1 Brainstorm ไอเดีย
```
Brainstorm ไอเดียเกี่ยวกับ [หัวข้อ]
ต้องการจำนวน: 10-20 ไอเดีย
แต่ละไอเดียมี: ชื่อ, คำอธิบายสั้น, กลุ่มเป้าหมาย, ความเป็นไปได้
```

### 3.2 วางแผนโปรเจกต์
```
ช่วยวางแผนโปรเจกต์ [ชื่อโปรเจกต์]
เป้าหมาย: [เป้าหมาย]
เวลา: [ระยะเวลา]
แบ่งเป็น phases พร้อม:
- งานที่ต้องทำ
- ทรัพยากรที่ต้องใช้
- ระยะเวลาแต่ละ phase
- ตัวชี้วัดความสำเร็จ
```

### 3.3 SWOT Analysis
```
วิเคราะห์ SWOT สำหรับ [ธุรกิจ/โปรเจกต์]
Strengths (จุดแข็ง):
Weaknesses (จุดอ่อน):
Opportunities (โอกาส):
Threats (อุปสรรค):
พร้อมข้อเสนอแนะเชิงกลยุทธ์
```

### 3.4 แผนธุรกิจแบบสั้น
```
เขียน Business Model Canvas สำหรับ [ไอเดียธุรกิจ]
1. Customer Segments
2. Value Propositions
3. Channels
4. Customer Relationships
5. Revenue Streams
6. Key Resources
7. Key Activities
8. Key Partnerships
9. Cost Structure
```

### 3.5 วางแผนการเงินส่วนตัว
```
ช่วยวางแผนการเงินส่วนตัวให้กับคนที่มี
รายได้: [จำนวน] บาท/เดือน
ค่าใช้จ่าย: [จำนวน] บาท/เดือน
เป้าหมาย: [ออม/ลงทุน/ชำระหนี้]
ให้คำแนะนำแบบละเอียด พร้อมตารางงบประมาณ
```

## 📂 หมวด 4: โค้ดดิ้งและการพัฒนา

### 4.1 เขียนฟังก์ชัน Python
```
เขียนฟังก์ชัน Python สำหรับ [สิ่งที่ต้องการ]
รับ input: [ชนิดข้อมูล]
คืนค่า: [ชนิดข้อมูล]
จัดการ error cases ด้วย
มี docstring และ comment ภาษาไทย
```

### 4.2 อธิบายโค้ด
```
อธิบายโค้ดต่อไปนี้ให้คนไทยเข้าใจง่าย
บอกว่าแต่ละส่วนทำงานอะไร
รวมถึง Big O และ performance considerations

[วางโค้ดที่นี่]
```

### 4.3 Debug โค้ด
```
ช่วยหา bug ในโค้ดนี้
อธิบายว่าปัญหาคืออะไร และวิธีแก้
แสดงโค้ดที่แก้ไขแล้ว

[วางโค้ดที่นี่]
```

### 4.4 SQL Query
```
เขียน SQL query สำหรับ:
[อธิบายว่าต้องการข้อมูลอะไร]
จากตาราง: [ชื่อตารางและคอลัมน์]
เพิ่ม: indexes, optimization tips
```

### 4.5 API Design
```
ออกแบบ REST API สำหรับ [ระบบที่ต้องการ]
รวม:
- Endpoints
- Methods
- Request/Response format
- Authentication
- Error handling
เขียนเป็นภาษาไทย
```

## 📂 หมวด 5: เทรนนิ่งและการเรียนรู้

### 5.1 อธิบาย概念
```
อธิบาย "[Concept]" ให้คนที่ไม่มีความรู้มาก่อนเข้าใจ
ใช้ภาษาไทยง่ายๆ 
เปรียบเทียบกับสิ่งใกล้ตัว
มีตัวอย่างประกอบ
ความยาว 500-800 คำ
```

### 5.2 สร้างแผนการเรียนรู้
```
สร้างแผนการเรียนรู้ "[วิชา/ทักษะ]" 30 วัน
แบ่งเป็น 4 สัปดาห์
แต่ละวันมี: หัวข้อ, กิจกรรม, ทรัพยากร
วัดผลความก้าวหน้า
```

### 5.3 ทำข้อสอบ/แบบฝึกหัด
```
สร้างแบบฝึกหัด 10 ข้อเกี่ยวกับ "[หัวข้อ]"
รูปแบบ: ปรนัย 4 ตัวเลือก
มีเฉลยและคำอธิบาย
ระดับความยาก: [ง่าย/กลาง/ยาก]
ภาษาไทย
```

### 5.4 สรุปหนังสือ/คอร์ส
```
ช่วยสรุป "[ชื่อหนังสือ/คอร์ส]"
แบ่งเป็น:
- แนวคิดหลัก (3-5 ข้อ)
- รายละเอียดแต่ละแนวคิด
- ตัวอย่างประยุกต์ใช้
- Key Takeaways
```

### 5.5 ทำ Flashcards
```
สร้าง Flashcards 20 อัน สำหรับ "[หัวข้อ]"
รูปแบบ: คำถาม → คำตอบ
ภาษาไทย
แบ่งหมวดหมู่
เหมาะสำหรับทบทวนก่อนสอบ
```
